# Planning workflow

When the user asks to plan, pressure-test, or make decisions about a plan, proposal, design, or architecture, use the `grill-me` skill when its interview format is appropriate. Follow that skill before presenting an implementation plan or proceeding to implementation.

When wrapping up a planning conversation, make the final optional question to the user: "Would you like me to use the `silent-treatment` skill while implementing this plan?" Ask it only when no higher-priority instruction, safety requirement, unresolved blocker, or required question from another applicable skill takes precedence.

This question does not imply consent to use `silent-treatment`, does not activate it automatically, and applies only to the implementation of the plan being discussed. It must not override the user's instructions, system or developer instructions, or the requirements of any other applicable skill.
