# Hamlet Arencibia AI Skills

A collection of reusable AI skills, prompts, workflows, and supporting resources designed to improve the capabilities of AI assistants and coding agents.

The goal of this repository is to provide practical, modular skills that anyone can use, modify, and build upon in their own projects.

## Features

- Reusable AI skills
- Easy to integrate into existing workflows
- Human-readable documentation
- Community-friendly structure
- Open source

## Repository Structure

```text
skills/
├── skill-1/
├── skill-2/
├── skill-3/
└── ...
```

Each skill contains its own documentation, instructions, and any supporting files it requires.

## Getting Started

1. Browse the `skills/` directory.
2. Choose a skill that fits your use case.
3. Copy or adapt it for your AI assistant, agent, or application.
4. Customize it as needed.

## Contributing

Contributions are welcome.

If you'd like to improve an existing skill or add a new one:

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Open a Pull Request with a clear description.

Please keep skills focused, well documented, and easy to reuse.

## Guidelines

- Keep skills self-contained whenever possible.
- Document assumptions and requirements.
- Prefer clear instructions over clever prompts.
- Write for both humans and AI agents.
- Include examples when appropriate.
